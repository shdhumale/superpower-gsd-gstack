## Vision

### 10x Check
Instead of a single-player "fake" dashboard, we swap `localStorage` for a zero-setup Backend-as-a-Service (like Firebase/Supabase) via client-side JS to instantly turn the MVP into a real-time, live-syncing, multiplayer emergency board.

### Platonic Ideal
The interface feels like an emergency dispatcher's HUD. Dark mode, glassmorphism, crisp typography. Critical tickets demand attention with subtle pulsing. Keyboard shortcuts make operations wildly fast.

## Scope Decisions

| # | Proposal | Effort | Decision | Reasoning |

| 1 | Real-time Multiplayer (BaaS) | M | ACCEPTED | The wow-factor of cross-tab live syncing justifies the extra hour of setup. |

## Accepted Scope (added to this plan)
- Client-side BaaS integration (e.g. Firebase or Supabase JS SDK) instead of purely `localStorage`.
- "Pulsing Red" CSS animation state for critical tickets.
- Keyboard shortcuts (`c` = new ticket, `/` = search focus, `esc` = close modal).
- Optimistic UI state updates with explicit visual rollback/"Sync Failed" icons.
- Native ES Modules (`type="module"`) layout to separate UI, DB, and state logic cleanly.
- Search input automatically debounced by 150ms for performance.
