## Affected Pages/Routes
- index.html — The main dispatcher HUD dashboard. Verify real-time BaaS integration and UI rendering.

## Key Interactions to Verify
- Create Ticket on index.html: Submitting a valid ticket with title and description immediately prepends it to the DOM (Atomic DOM updates).
- Keyboard shortcuts: Press `c` to open creation modal. Press `Esc` to close modal. Press `/` to focus search.
- Search Filter: Typing should filter tickets immediately (150ms debounce) without throwing layout errors.

## Edge Cases
- Modal Close with Data: Striking `Esc` while text exists inside the description field must trigger a browser `confirm()` popup to prevent accidental data loss.
- Double Submit: The "Submit" button must disable immediately upon click to prevent submitting duplicate tickets.
- Silent Network Failure: Creating a ticket with public read/write blocked (DB Reject) MUST gracefully rollback the UI ticket and show a "Sync Failed" visual error over that ticket.

## Critical Paths
- Ticket live-sync: A ticket created in Tab A must instantly appear in Tab B via BaaS websocket subscription without a page refresh.
